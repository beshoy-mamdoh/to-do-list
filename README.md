# 📝 To-Do List Application (تطبيق مهامي)

A modern, responsive, and clean looking Arabic To-Do List web application built using native web technologies. It allows users to manage their daily tasks efficiently with a smooth and delightful user experience.

تطبيق ويب حديث ومتجاوب لإدارة المهام اليومية باللغة العربية، مبني باستخدام تقنيات الويب الأساسية. يتيح للمستخدمين تنظيم مهامهم بكفاءة مع تجربة مستخدم سلسة وممتعة.

🚀 **Live Demo / رابط المعاينة المباشرة:** `https://beshoy-mamdoh.github.io/to-do-list/`

---

## 🌍 English Description

### ✨ Features
- **Fully Responsive Design:** Styled from the ground up using CSS Flexbox and Media Queries to look stunning on ultra-wide monitors, tablets, and mobile devices.
- **Micro-interactions & Keyframes:** - Smooth dynamic slide-up animation (`@keyframes`) when tasks render.
  - Interactive hover state effects on task cards.
  - Rotational and scaling feedback on button clicks.
- **Persistent Storage:** Tasks are automatically saved locally using the browser's `localStorage` API, preventing data loss on page refreshes.
- **CRUD Functionality:** Full capabilities to Add, Read, Update, and Delete tasks seamlessly via intuitive alert/prompt feedback.
- **Clean Architecture:** Strict separation of concerns (HTML, CSS, JS isolated in dedicated files) for production-ready code maintainability.

### 🛠️ Tech Stack & Assets
- **Frontend:** HTML5, CSS3 (Modern Gradients & Animations).
- **Logic:** Vanilla JavaScript (ES6+ features).
- **Fonts:** "Tajawal" via Google Fonts.
- **Icons:** Material Symbols & FontAwesome v7.0.1.

## 🌍 الوصف باللغة العربية

### ✨ المميزات والتحديثات
- **تصميم متجاوب بالكامل:** تم بناؤه باستخدام CSS Flexbox و Media Queries ليعمل بشكل ممتاز ومريح على الشاشات الكبيرة، أجهزة التابلت، والهواتف المحمولة.
- **تأثيرات حركية تفاعلية (Keyframes):**
  - حركة صعود ناعمة وانسيابية عند ظهور المهام الجديدة.
  - تأثيرات بصرية عند تحويم الماوس (Hover) على بطاقات المهام.
  - تفاعل الأزرار والدوران عند الضغط عليها لتعزيز تجربة المستخدم.
- **حفظ دائم للبيانات:** يتم حفظ المهام تلقائياً في المتصفح باستخدام الـ `localStorage` لمنع ضياع البيانات عند إعادة تحميل الصفحة.
- **إدارة كاملة للمهام (CRUD):** إمكانية إضافة، قراءة، تعديل، وحذف المهام بكل سهولة من خلال نوافذ تفاعلية سلسة.
- **بنية كود نظيفة (Clean Architecture):** فصل كامل للملفات (HTML, CSS, JS) لجعل المشروع احترافي، منظم، وسهل التطوير مستقبلاً.

### 🛠️ التقنيات المستخدمة
- **الواجهة الأمامية:** HTML5, CSS3 (تأثيرات حركية وتدرجات ألوان عصرية).
- **المنطق والتحكم:** Vanilla JavaScript (ميزات ES6+).
- **الخطوط:** خط "Tajawal" عبر Google Fonts.
- **الأيقونات:** Material Symbols و FontAwesome v7.0.1.
